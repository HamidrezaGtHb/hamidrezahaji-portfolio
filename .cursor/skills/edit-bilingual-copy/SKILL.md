# Edit bilingual copy

1. Open `content/i18n.ts` and/or `content/projects.ts`.
2. Change **en and de** in the same edit for every key touched.
3. Keep tone: calm, clear, Germany-first employer voice. DE should be natural, not literal word-for-word if that hurts readability.
4. Do not invent new top-level sections without wiring both languages into the consuming component.
5. After copy-only edits: no deploy unless the user asks.
